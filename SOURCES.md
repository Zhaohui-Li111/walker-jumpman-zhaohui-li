## 2. Art and assets

**All visual content is original vector drawing executed in code by Godot's `CanvasItem` API.**
No imported art, no sprite sheets, no texture files, no fonts beyond `ThemeDB.fallback_font`
(shipped with Godot), no audio. Nothing was downloaded, purchased, or generated by an image model.

| Asset | Where | Provenance |
|---|---|---|
| BEACON (the character) | `godot/features/player/player.gd::_draw()` | Original. Drawn with `draw_rect`, `draw_circle`, `draw_colored_polygon`. Concept and palette are mine; not derived from any existing character. |
| Zone 03 terrain, spikes, flag, hills, grid | `godot/game/session.gd::_draw()` | Original, extending the starter's drawing idiom. |
| Character contact sheet | `evidence/screens/05-character-states.png` | Rendered by `godot/tests/capture_character.gd` from the real `_draw()` output. **Labelled as a fixture, not gameplay** — bodies are frozen deliberately to show six poses side by side. |
| Gameplay screenshots | `evidence/screens/01-04, 06-09` | Real engine viewport captures via `root.get_texture().get_image()`. Not desktop screenshots, not mock-ups. Driven by scripted input, which the film labels as such. |

BEACON's palette: `#f0b429` amber shell, `#6b4b8a` plum pack/boots, `#5ee7d0` cyan visor,
`#1f2b3d` ink. Chosen by me to separate from the starter's `#287baf`/`#ef875f` figure and to
read against the cream `#f6f3ec` background.

## 6. Blocked dependency: the Brutalist explainer skill

The assignment requires the course-provided **Brutalist `godot-walkthrough`** skill (original
spelling `godot-waikthrough`) with the `walker` modifier, and says: *"If your checkout lacks the
skill, request the course-provided version before proceeding."*

**It is not present on this machine.** Verified by searching `~/.claude/` (no `skills/`
directory exists), `~/.claude/plugins/` (only the official Claude marketplace), and the
`D:\courses` tree, for `brutalist`, `walkthrough` and `waikthrough`. No match.

The film has therefore **not** been produced, and no substitute workflow was used in its place —
producing a video by some other route and calling it a Brutalist explainer would misrepresent
the workflow used. `film/` contains the beat sheet, narration script and evidence index prepared
for that workflow, so the render is the only remaining step once the skill is available.
